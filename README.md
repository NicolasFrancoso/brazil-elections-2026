
# Brazil Elections 2026 Analytics

An end-to-end electoral intelligence platform built with
official Brazilian election data.

## Objective

This project explores the Brazilian 2026 general election through
data engineering, analytics, visualization and machine learning.

The project covers:

- Candidate intelligence
- Electorate analysis
- Electoral polls
- Electoral geography
- Campaign finance
- Predictive modeling
- Election simulation

## Data Sources

- Tribunal Superior Eleitoral (TSE)
- Instituto Brasileiro de Geografia e Estatística (IBGE)

## Tech Stack

- Python
- pandas
- DuckDB
- Parquet
- Power BI
- scikit-learn
- Streamlit
